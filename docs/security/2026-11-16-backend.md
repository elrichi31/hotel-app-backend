## Condiciones verificadas y riesgos que siguen abiertos

- [Traversal oficial](https://github.com/adonisjs/core/security/advisories/GHSA-gvq6-hvvp-h34h): requiere move sin nombre seguro. Único uso de upload de la app en ConfiguracionController pasa nombre generado a moveToDisk. Test real de MultipartFile + disco demuestra que ../../outside.png se guarda como logos/UUID.png, conservando bytes. Esto cubre este flujo, no parchea el paquete genérico.
- [DoS multipart](https://github.com/adonisjs/core/security/advisories/GHSA-xx9g-fh25-4q64) y [prototype pollution](https://github.com/adonisjs/core/security/advisories/GHSA-f5x2-vj4h-vg4c): parche oficial bodyparser10.1.3/11 prerelease; npm muestra8.1.9 como última8.x. No existe backport oficial8.x identificado. El límite global20mb ya existía, pero no elimina buffering ni el riesgo agregado por concurrencia. BodyParser global se ejecuta antes del middleware auth, por lo que proteger solo la ruta de configuración no elimina exposición al parser. No se implementó ni se proclama mitigación total de estos dos avisos.
- [proxy-addr](https://github.com/jshttp/proxy-addr/security/advisories/GHSA-jqcg-44mw-7w3h): config actual compile('loopback') no usa subred malformada del aviso. Se actualiza2.0.8 y prueba loopback, rechazo de direcciones externas y rechazo de IPv4 externa con subred mapeada mal formada. No se afirma explotación previa de la configuración actual.
- Lucid: RegistroPersonasController.store pasa personasData a createMany; FacturasController pasa productos de entrada a creación de relaciones; HabitacionesController también crea precios desde entrada. Deben cubrirse con allowlists y pruebas de rechazo de claves internas al migrar; no están saneados por este parche de dependencias. No se verificó explotación.
- Nodemailer continúa6.x por mail8; no se impone10.x mediante override. Revisar destinatarios suministrados por usuarios y mantener pruebas de correo en transporte de prueba durante la migración.
- Cookie y file-type quedan sujetos a versiones del framework. No se desactivan uploads, correos, rutas ni alertas para bajar el audit.
